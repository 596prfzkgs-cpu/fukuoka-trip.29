## GitHub Pages 배포
1. 저장소의 기존 `index.html`을 새 파일로 교체합니다.
2. 저장소 최상위(root)에 `index.html`이 위치하도록 합니다.
3. 변경 사항을 Commit합니다.
4. GitHub Pages가 `main` 브랜치의 `/(root)`를 배포하도록 설정되어 있는지 확인합니다.

체크리스트 상태는 브라우저의 로컬 저장소에 보관되며 기기 간 자동 동기화되지 않습니다.
